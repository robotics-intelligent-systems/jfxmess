# Artificial Intelligence for Modular Energy System Simulation

Data models related to the Energy Domain. NeqSim Community Agents is the public open-source repository for community-developed AI agents. PyPSA is an open-source framework for optimising and simulating modern power and energy systems. Antares Simulator is an open-source power system simulator. Mosaik is a flexible Smart Grid co-simulation framework. Dynaωo is a hybrid C++/Modelica open source suite of simulation tools. The SMArtInt Library is designed to integrate various artificial intelligence (AI) models. The OpenHPL is an open-source hydropower library. HanserModelica is a Modelica library applied to electrical engineering. OSeMOSYS is a full-fledged systems optimization model. OpenFAST is a wind turbine simulation tool. H2Integrate is a Python package for modeling and designing hybrid energy systems. OpenOA is a framework for assessing wind plant performance. ThermoSysPro is a library providing model components in the disciplines of thermal hydraulics. A Modelica library for photovoltaic system and power converter design. Research Reactor Simulator is a real-time graphical simulation. OpenReactor is a comprehensive nuclear reactor simulation tool. A package for Modelica simulating Molten Salt Reactors. The ThermoCycle library is a library for dynamic modelling of thermal systems. preCICE is a coupling library for partitioned multi-physics simulations. PowerGrids, a Modelica library for electro-mechanical modelling. DSNP is a system of programs and data files used to simulate nuclear power plants. DDNRS-ERSN is an Open Nuclear Reactor Simulator. ClaRa is a Modelica library for simulation of Clausius-Rankine cycles in power plants. MOOSE is an object-oriented C++ finite element framework. Armi is an open-source nuclear reactor analysis automation framework. Wind Plant Integrated System Design and Engineering Model. WindSE is a package that uses a FEniCS backend to perform wind farm simulations. WInc3D provides an integrated wind farm simulation framework

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
