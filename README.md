Hy4GreenIT Simulation model of a hydrogen-based Green IT facility. OpenRESV is an open-source Modelica-based library that is focused on modeling and validation of WECC-based renewable energy models. Design optimization of FOWT. Open Energy Modelling Framework. BEMRosetta hydrodynamic solvers. oc4-floatfoam is an OpenFOAM case repository for wave–structure interaction simulations. OpenDSS to Typhoon HIL interface library. Mosaik is a flexible Smart Grid co-simulation framework. Dynaωo is a hybrid C++/Modelica open source suite of simulation tools. The OpenHPL is an open-source hydropower library. HanserModelica is a Modelica library applied to electrical engineering. OSeMOSYS is a full-fledged systems optimization model. OpenFAST is a wind turbine simulation tool. SHARPy is a modular aeroelastic solver. H2Integrate is a Python package for modeling and designing hybrid energy systems. OpenOA is a framework for assessing wind plant performance. ThermoSysPro is a library providing model components in the disciplines of thermal hydraulics. A Modelica library for photovoltaic system and power converter design. Wind Plant Integrated System Design and Engineering Model. WindSE is a package that uses a FEniCS backend to perform wind farm simulations. WInc3D provides an integrated wind farm simulation framework. The ThermoCycle library is a library for dynamic modelling of thermal systems. preCICE is a coupling library for partitioned multi-physics simulations. PowerGrids, a Modelica library for electro-mechanical modelling. HYBRID is a collection of a transient process models developed in the Modelica langauage capable of representing the physical dynamics of various integrated energy systems and processes. Wind Turbine Prognostics and Health Management library

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
